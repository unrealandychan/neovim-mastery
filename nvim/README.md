# Eddie's Neovim Configuration

A modern, high-performance Neovim setup built on top of [LazyVim](https://www.lazyvim.org/).

## 🎨 Theme
- **Primary**: Tokyo Night (`tokyonight-night`)
- **Alternatives installed**: Catppuccin, Gruvbox, OneDark

## ⚡ Languages Supported
- **TypeScript / JavaScript & Web**: `vtsls`, `prettier`, `eslint`, `tailwindcss`
- **Python**: `pyright`, `ruff`, `venv-selector`
- **Go**: `gopls`, `gofumpt`, `goimports`, `golangci-lint`
- **Rust**: `rust-analyzer` via `rustaceanvim`, `crates.nvim`, `codelldb`
- **Flutter / Dart**: `dartls`, `flutter-tools.nvim`, widget closing tags
- **Configs**: JSON, YAML, TOML, Dockerfile, Bash

## 🚀 Quick Commands
- `<Space><Space>` : Find files
- `<Space>/` : Grep search in project
- `<Space>e` : Toggle file tree explorer
- `<Space>gg` : LazyGit floating window
- `<Space>cm` : Mason (LSP / Tool manager)
- `:Lazy` : Plugin manager
- `:LazyExtras` : Toggle additional language & AI modules
